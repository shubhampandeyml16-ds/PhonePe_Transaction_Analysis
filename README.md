# PhonePe_Transaction_Analysis
** Project Overview **

-> This project presents an interactive **PhonePe Transaction Analysis dashboard developed in Microsoft Power BI** to analyze transaction performance, user behavior, payment status, service contribution, and demographic patterns.

-> The dashboard transforms raw transaction data into meaningful business insights through interactive visualizations, KPI tracking, trend analysis, and user segmentation.

## 🎯 Business Objectives

- Analyze overall transaction volume and transaction value
- Track monthly transaction trends and growth
- Evaluate transaction success rates and payment status
- Understand user behavior and transaction contribution
- Analyze transaction value across different services
- Compare weekday and weekend transaction activity
- Identify top users based on transaction value
- Analyze transaction contribution across age segments
